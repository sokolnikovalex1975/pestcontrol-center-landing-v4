# ПЕСТКОНТРОЛЬ Центр — лендинг

Лендинг пест-контроля для бизнеса в Москве и Московской области.

- Сайт: [пестконтроль-центр.рф](https://xn----itbbsflddbfpfdodg9d0f.xn--p1ai/)
- Тестовая версия (GitHub Pages): [sokolnikovalex1975.github.io/pestcontrol-center-landing](https://sokolnikovalex1975.github.io/pestcontrol-center-landing/)

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Главная страница. На хостинге — `index.php` со счётчиками из `server/counters.html` |
| `style.css`, `app.js` | Стили и скрипты лендинга |
| `privacy/`, `soglasie/` | Политика конфиденциальности и согласие на обработку персональных данных |
| `legal.css` | Стили страниц документов |
| `img/`, `fonts/`, `vendor/` | Изображения, шрифт Inter, библиотеки анимации GSAP, ScrollTrigger и Lenis |
| `server/` | Файлы, которые работают только на хостинге: обработчик формы, `.htaccess`, `robots.txt`, `sitemap.xml`, счётчики |
| `tools/legal/` | Генератор страниц документов с расстановкой неразрывных пробелов |

## Тестовая версия

Корень репозитория публикуется на GitHub Pages. В тестовой версии нет счётчиков UIS и Яндекс Метрики, а форма работает в демо-режиме: показывает «Заявка отправлена», но никуда не передаёт данные. Демо-режим включается только на домене `github.io`.

## Выкладка на хостинг

Сайт размещён на виртуальном хостинге Timeweb, каталог `public_html`.

1. Загрузите файлы из корня репозитория. Переименуйте при загрузке:
   - `index.html` → `index.php`, вставив два блока из `server/counters.html`;
   - `privacy/index.html` → `privacy/index.php`;
   - `soglasie/index.html` → `soglasie/index.php`.
2. Из папки `server/` загрузите в корень сайта `.htaccess`, `robots.txt` и `sitemap.xml`.
3. Не перезаписывайте `send.php` на сервере: только там указаны пароль почты и адрес, на который приходят заявки. В репозитории вместо них заглушки. Если меняете обработчик, перенесите эти две строки из серверной версии.
4. PHPMailer 7.1 установлен на сервере в `vendor/` через Composer (`server/composer.json`) и в репозиторий не входит.
5. Статические файлы сервер кэширует на год. После изменения `style.css`, `app.js` или `legal.css` поменяйте параметр `?v=` в ссылках на них, иначе посетители получат старую версию.

## Документы

Тексты политики и согласия собираются скриптом `python3 tools/legal/build_legal.py`. Оператор персональных данных указан одной строкой внизу каждой страницы.
