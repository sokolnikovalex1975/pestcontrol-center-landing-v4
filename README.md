# ПЕСТКОНТРОЛЬ Центр — лендинг, редакция v4

Новая редакция главной страницы [пестконтроль-центр.рф](https://xn----itbbsflddbfpfdodg9d0f.xn--p1ai/): постоянный пест-контроль для бизнеса в Москве и Московской области. Дизайн прежний; тексты, порядок блоков и метаданные переработаны, чтобы страница не повторяла агерис.рф/audit.

- Предпросмотр: [sokolnikovalex1975.github.io/pestcontrol-center-landing-v4](https://sokolnikovalex1975.github.io/pestcontrol-center-landing-v4/)
- Список правок и вопросы на подтверждение: [CHANGES.md](CHANGES.md)
- **Опубликовано на пестконтроль-центр.рф 22.10.2026** из ветки `main` (коммит с этой записью). Копия сайта до публикации: `/backups/public_html_backup_2026-10-22_before-v4.zip` на хостинге, вне публичного каталога.
- Прежняя опубликованная версия (до v4): репозиторий [pestcontrol-center-landing](https://github.com/sokolnikovalex1975/pestcontrol-center-landing)

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | Файлы для сайта. Именно их выкладывать на хостинг после согласования |
| `gh-pages` | Копия `main` для предпросмотра на GitHub Pages; в страницы добавлен `noindex`, чтобы тестовая копия не попала в поиск |

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Главная страница. На хостинге — `index.php` со счётчиками из `server/counters.html` |
| `style.css`, `app.js` | Стили и скрипты лендинга |
| `privacy/`, `soglasie/` | Политика конфиденциальности и согласие на обработку персональных данных |
| `legal.css` | Стили страниц документов |
| `img/`, `fonts/`, `vendor/` | Изображения, шрифт Inter, библиотеки анимации GSAP, ScrollTrigger и Lenis |
| `server/` | Файлы, которые работают только на хостинге: обработчик формы, `.htaccess`, `robots.txt`, `sitemap.xml`, счётчики |
| `tools/legal/` | Генератор страниц документов с расстановкой неразрывных пробелов |

## Тестовая версия

Ветка `gh-pages` публикуется на GitHub Pages. В тестовой версии нет счётчиков UIS и Яндекс Метрики, а форма работает в демо-режиме: показывает «Заявка отправлена», но никуда не передаёт данные. Демо-режим включается только на домене `github.io`.

## Выкладка на хостинг

Сайт размещён на виртуальном хостинге Timeweb, каталог `public_html`.

1. Загрузите файлы из корня ветки `main` (кроме `README.md`, `CHANGES.md` и `tools/`). Переименуйте при загрузке:
   - `index.html` → `index.php`, вставив два блока из `server/counters.html`;
   - `privacy/index.html` → `privacy/index.php`;
   - `soglasie/index.html` → `soglasie/index.php`.
2. Из папки `server/` загрузите в корень сайта `.htaccess`, `robots.txt` и `sitemap.xml`.
3. Не перезаписывайте `send.php` на сервере: только там указаны пароль почты и основной адрес, на который приходят заявки. В репозитории вместо них заглушки. Если меняете обработчик, перенесите эти две строки из серверной версии. Копия каждой заявки уходит также на b2b@pestcontrol-center.ru (`$toEmailB2b`, с 22.10.2026).
   **Для v4 обязательно** перенесите в серверный `send.php` две правки из репозитория:
   - в список `$allowedTypes` — строку `'Фармацевтическое производство',`, иначе заявки с этим типом объекта сервер отклонит с ошибкой «Выберите тип объекта»;
   - `$consentVersion = '22.10.2026';` — в письме с заявкой должна стоять действующая редакция согласия (сменился оператор персональных данных).
4. PHPMailer 7.1 установлен на сервере в `vendor/` через Composer (`server/composer.json`) и в репозиторий не входит.
5. Изображения v4 загружаются под новыми именами: `ind-bakery.webp`, `ind-kitchen.webp`, `ind-hotel-room.webp`, `ind-pharma.webp`, `p-pigeon.webp`, `p-bedbug-macro.webp`, `p-moth.webp`. Сервер кэширует картинки на год, поэтому файл с прежним именем и новым содержимым посетители увидели бы не сразу. Старые файлы больше не используются, их можно удалить: `ind-elevator.webp`, `ind-food.webp`, `ind-horeca.webp`, `ind-hotel.webp`, `p-bird.webp`, `p-bedbug.webp`, `p-stored.webp`. В `server/sitemap.xml` поставьте дату выкладки в `lastmod`.
6. Статические файлы сервер кэширует на год. После изменения `style.css`, `app.js` или `legal.css` поменяйте параметр `?v=` в ссылках на них, иначе посетители получат старую версию.

## Документы

Тексты политики и согласия собираются скриптом `python3 tools/legal/build_legal.py`. Оператор персональных данных — ООО «Центр дезинфекционных услуг» (ИНН 7714462211, КПП 771401001, ОГРН 1207700257775) — указан одной строкой внизу каждой страницы; реквизиты и контактная почта задаются в начале скрипта.
